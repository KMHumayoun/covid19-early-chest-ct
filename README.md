# Detecting COVID-19 on chest CT

How well can a model trained on selected CT slices distinguish patients with COVID-19 from patients with other lung conditions or healthy lungs? A separate case review asks what the same model does on published images taken on the first day of symptoms.

The main study uses a collection from two hospitals in São Paulo. All slices from a patient stay together. Early cases come from a separate collection with figure captions that document symptom timing. The public files contain the analysis and aggregate results. The source images are available from their authors.

[Original CT collection](https://doi.org/10.7910/DVN/SZDUQX) · [COVID-CT data paper](https://arxiv.org/abs/2003.13865)
